<threat_model>
### ASVS L1 Threat Model: Webhooks & WhatsApp Notifications
- **T-12-01 (SSRF via Webhook Endpoints)**: Malicious administrator configures webhook URL targeting internal cloud metadata (`169.254.169.254`) or loopback services (`127.0.0.1`).
  - *Mitigation*: Strictly validate webhook URL scheme (`http:`, `https:`). Reject private/link-local/loopback IP addresses in production mode.
- **T-12-02 (Secrets Leakage in REST APIs)**: Webhook HMAC secrets or WhatsApp API keys exposed in plain text in GET API responses.
  - *Mitigation*: Never return raw secrets in GET responses; mask secrets in API serialization (`whsec_***`).
- **T-12-03 (Replay Attacks on Outbound Webhooks)**: Intercepted webhook replayed against external barrier systems.
  - *Mitigation*: Sign request payload with HMAC-SHA256 and include `X-VMS-Timestamp` and `X-VMS-Delivery` headers. Receivers can reject deliveries older than 300 seconds.
- **T-12-04 (Notification Flooding & API Exhaustion)**: High-frequency motion events exhaust WhatsApp API quotas and spam recipient phones.
  - *Mitigation*: Enforce token-bucket rate limiter with a mandatory 60-second anti-spam cooldown per camera.
</threat_model>

         - Subscribes to `EventBus` (`motion.detected`, `camera.offline`, `camera.tamper`).

         - Formats message with snapshot URL and IST timestamp.
         - Dispatches alert via active provider.
         - Export singleton `notificationService`.
    2. Create `src/webhooks/webhook.types.ts`:
       - DTOs and delivery payload schemas.
    3. Create `src/webhooks/webhook-dispatcher.service.ts`:
       - Class `WebhookDispatcherService`:
         - Subscribes to `EventBus` events.
         - Computes HMAC-SHA256 signature using endpoint shared secret.
         - Sends HTTP POST with `X-VMS-Signature`, `X-VMS-Timestamp`, `X-VMS-Event`, `X-VMS-Delivery`.
         - Validates URLs against SSRF: rejects loopback/metadata IPs in production.
         - Asynchronous non-blocking queue with timeout (5000ms) and retry logic.
         - Export singleton `webhookDispatcherService`.
  </action>

    Run `npx tsc --noEmit` to verify compilation.
  </verify>
</task>
