<threat_model>
<threat>
T-04-01: Unauthorized access to live camera feeds
Severity: high
Mitigation: Streaming configuration endpoint is protected by JWT authentication (authenticate hook).
</threat>
<threat>
T-04-03: Client CPU / GPU exhaustion via multiple simultaneous 4K streams
Severity: high
Mitigation: Automatically select subStreamPath for 2x2 and 3x3 grid layouts; reserve mainStreamPath for 1x1 or solo full-screen.
</threat>
<threat>
T-04-04: XSS via unescaped camera names in grid tiles
Severity: medium
Mitigation: Camera names rendered strictly via standard React text nodes without dangerouslySetInnerHTML.
</threat>
</threat_model>
