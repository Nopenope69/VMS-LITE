<threat_model>
<threat>
T-07-03: Viral copyleft (GPL/AGPL) license contamination in production release
Severity: high
Mitigation: Automated license auditor strictly enforces whitelist: ['MIT', 'Apache-2.0', 'BSD-2-Clause', 'BSD-3-Clause', 'ISC', '0BSD']; fails CI build if any unapproved license is detected.
</threat>
<threat>
T-07-04: State corruption on ungraceful power loss / storage unmount
Severity: medium
Mitigation: Verify crash recovery in smoke tests; ensure Prisma connections and in-memory caches re-synchronize cleanly on reboot.
</threat>
</threat_model>

  <files>scripts/audit-licenses.js, package.json</files>
  <action>
    - Create `scripts/audit-licenses.js`:

  </action>
