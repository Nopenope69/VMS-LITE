# Plan 15-02: Frontend 6-Step Camera Onboarding Wizard Modal

## Objective
Build a comprehensive 6-step camera onboarding wizard component (`CameraOnboardingWizardModal.tsx`) that guides the installer through discovery, credentials verification, network port check, stream provisioning, visual WebRTC preview confirmation, and atomic database commit.

## Tasks

1. **Build `CameraOnboardingWizardModal.tsx`**:
   - Visual step indicator (Steps 1 to 6) with status icons (complete, current, pending).
   - **Step 1 (Discovery & Ingress Method)**:
     - Subnet WS-Discovery probe button with scan progress spinner.
     - Discovered camera list with IP address, MAC, and vendor badges (Hikvision, CP Plus, Dahua, Generic ONVIF).
     - Manual IP / RTSP entry toggle.
   - **Step 2 (Authentication & Stream Profiles)**:
     - Username & password fields.
     - "Probe Camera" action triggering `POST /api/cameras/probe-auth`.
     - Displays manufacturer, model, firmware, and available profiles (marking Main HD stream and Sub-stream).
   - **Step 3 (Network Port Verification)**:
     - Automatically verifies RTSP port 554 connectivity via `POST /api/cameras/probe-network`.
     - Displays round-trip latency (e.g. `12ms`) and packet reachability badge.
   - **Step 4 & 5 (Stream Provisioning & Live WebRTC Preview)**:
     - Calls `POST /api/cameras/provision-preview`.
     - Renders embedded `WhepHlsPlayer` with live video stream.
     - Installer visually inspects video feed and clicks "Confirm Stream & Proceed".
   - **Step 6 (Review & Atomic Commit)**:
     - Sets friendly camera name (e.g., "Front Gate", "Cash Counter").
     - Selects default recording policy (24/7 Continuous).
     - Submits `POST /api/cameras/commit`.
     - On success: closes wizard and refreshes camera roster.
   - **Teardown on Cancel**:
     - If preview path was created and user cancels or closes modal, invokes `POST /api/cameras/teardown-preview`.

2. **Integrate into `client/src/App.tsx`**:
   - Replace the legacy inline add camera modal with `CameraOnboardingWizardModal`.
   - Refresh camera list and health telemetry on successful onboarding.

3. **Export Component in `client/src/index.ts`**:
   - Export `CameraOnboardingWizardModal`.
