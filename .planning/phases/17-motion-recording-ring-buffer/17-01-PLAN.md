# Plan 17-01: Zero-Transcode Rolling Ring Buffer Engine

## Objective
Implement `MotionRingBufferEngine` managing short (e.g. 2-second) rolling video segments in an unpromoted FIFO ring buffer per camera, automatically unlinking expired segments during quiet periods, and atomically promoting a 10-second pre-buffer and 30-second post-buffer into permanent database-cataloged recordings upon ONVIF `motion.detected` events.

## Tasks

1. **Build `MotionRingBufferEngine` (`src/recordings/motion-ring-buffer.ts`)**:
   - Manages per-camera ring buffer state (`BufferedSegment` array): `segmentPath`, `duration`, `startTime`, `sizeBytes`, `mediaMtxPath`.
   - Discards segments older than `bufferTtlMs` (default 30 seconds) via injectable `fsUnlinkFn`.
   - Listens to `EventBus` for `motion.detected`:
     - Checks if camera is in motion-enabled mode.
     - Sets active motion state: `incidentActive = true`, `postBufferUntil = now + postBufferMs`.
     - Identifies all buffered segments within `now - preBufferMs` to `now`.
     - Promotes them to permanent recordings by invoking `catalog.ingestSegment` or `repository.createRecording`.
   - On incoming segment:
     - If camera has active motion or `now < postBufferUntil`:
       - Immediately ingests to permanent catalog.
     - Else:
       - Adds to rolling ring buffer queue.
       - Runs pruning tick to discard expired unpromoted segments from disk.
   - Provides methods:
     - `handleSegment(payload)`
     - `triggerMotion(cameraId, timestamp)`
     - `getBufferStatus(cameraId?)`
     - `clear()`

2. **Integrate with `RecordingEngine` (`src/recordings/recording-engine.ts`)**:
   - Instantiate `MotionRingBufferEngine` and wire it with `EventBus`, `RecordingCatalog`, and `IClock`.
   - In `ingestSegment(payload)`:
     - Check camera schedule / mode.
     - If `mode === 'MOTION_ONLY'`, route through `motionRingBuffer.handleSegment(payload)`.
     - If `CONTINUOUS` or scheduled active, ingest directly into permanent catalog.

3. **Integration Tests (`tests/motion-ring-buffer.test.ts`)**:
   - Test FIFO pruning when no motion occurs (segments deleted from disk, zero database records).
   - Test `motion.detected` promotes preceding 10s pre-buffer segments into permanent recordings.
   - Test segments arriving during motion are saved immediately.
   - Test 30s post-buffer extension on subsequent motion triggers.
   - Test cooldown expiration returns camera to rolling ring buffer mode.
