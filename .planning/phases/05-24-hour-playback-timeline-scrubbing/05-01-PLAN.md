      - `PlaybackService` class injecting `PrismaClient` and `RecordingService`.
      - `getTimelineSpans(cameraId, dateOrStart, end?)`:
        - Computes 24h start/end bounds (e.g. 00:00:00 to 23:59:59.999 UTC).

        - Resolves camera's `mediaMtxPath`.
        - Constructs MediaMTX fMP4 playback URL: `${playbackBaseUrl}/get?path=${mediaMtxPath}&start=${isoStart}&duration=${duration}`.
      - Handles fallback to direct segment file path if MediaMTX playback server is bypassed.
