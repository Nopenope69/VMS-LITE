# Plan 13-02: Test Isolation, Test Fixes & Golden Installer Path

## Objective
Establish clean, explicit test mock factories in `tests/mocks/` so unit tests can run deterministically without modifying production runtime code. Fix existing date-drift in `tests/playback.test.ts`, and implement the automated Golden Installer Path integration test verifying the end-to-end lifecycle.

## Tasks

1. **Create Reusable Prisma Mock Factory**:
   - Create `tests/mocks/prisma.mock.ts` with type-safe in-memory collections for `camera`, `bookmark`, `webhookEndpoint`, `notificationConfig`, and `event`.
   - Provide an easy factory function `createMockPrisma()` that implements the required Prisma query methods (`findMany`, `findUnique`, `create`, `upsert`, `update`, `delete`).

2. **Update Unit Tests to Use Explicit Dependency Injection**:
   - In `tests/export-bookmarks.test.ts`, inject the mock Prisma into `BookmarkService` and `ExportService` where isolated unit testing is performed.
   - In `tests/webhooks-alerts.test.ts`, inject the mock Prisma into `WebhookDispatcherService` and `NotificationDispatcherService`.
   - Verify that all unit tests pass cleanly without requiring production services to maintain in-memory maps.

3. **Fix Date Drift in `tests/playback.test.ts`**:
   - In `tests/playback.test.ts`, dynamically construct the dummy segment path using `todayStr` (e.g. `/var/recordings/${camera.mediaMtxPath}/${todayStr}_10-00-00.mp4`).
   - Verify `GET /api/playback/timeline` passes with $\ge 1$ spans.

4. **Implement Golden Installer Path Test**:
   - Create `tests/golden-installer-path.test.ts`.
   - Test end-to-end flow:
     1. App initialization and health check (`/health`).
     2. Admin login and JWT acquisition (`/api/auth/login`).
     3. Camera onboarding (`/api/cameras`).
     4. MediaMTX path synchronization verification.
     5. Recording ingestion and catalog lookup (`/api/playback/timeline`).
     6. Video clip export request (`/api/export`).
     7. Explicit failure testing: assert that when DB operations fail, routes return HTTP 503 rather than false 200.

## Verification
- Run `npm test` and assert all test suites pass.
- Run `npm run build` and assert 0 TypeScript compilation errors.
