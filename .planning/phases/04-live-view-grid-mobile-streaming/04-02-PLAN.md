    - Create `src/streaming/ice-servers.service.ts`:
      - `IceServerService` class generating STUN and TURN configurations.
      - Supports public STUN servers (e.g., Google or self-hosted Coturn `stun:<host>:3478`).
      - Supports Coturn long-term credential mechanism / REST API authentication (RFC 5766 TURN REST API):
        - Calculates expiration timestamp: `const expiry = Math.floor(Date.now() / 1000) + ttlSeconds`.

    - Create `tests/ice-servers.test.ts` testing STUN URLs, TURN ephemeral credential creation, HMAC correctness, and TTL validity.
