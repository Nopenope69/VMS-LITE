<threat_model>
### ASVS L1 Threat Model: Clip Export & Bookmarking UI
- **T-10-01 (Export Request Flooding & CPU Degradation)**: Operator triggers duplicate background transcode jobs or confusing stream-copy with heavy rendering.
  - *Mitigation*: Client clearly presents mode choice between "Original / Stream Copy (Fast - No Re-encoding)" and "Rendered Export / Transcoded Derivative (OSD)"; disables submit button while export job is QUEUED or RUNNING.
- **T-10-02 (Unauthorized Access Exposure)**: Users without export permission see active download controls.
  - *Mitigation*: Gated by `canExportClips` and role checking; UI hides the Export button if permission is absent.
- **T-10-03 (Tamper Transparency)**: Operator needs to verify the downloaded clip was unchanged.
  - *Mitigation*: Display explicit "SHA-256 integrity checksum" badge with one-click copy and header validation.
</threat_model>

<task type="auto" name="clip-export-modal-component">
  <action>
    1. Create `client/src/components/ClipExportModal.tsx`:
       - Props: `{ isOpen: boolean; onClose: () => void; cameraId: string; cameraName: string; initialStartTime?: Date; initialEndTime?: Date }`.
       - Mode Selection:
         - **Original / Stream Copy (Fast)**: "Preserves exact camera packets with zero decoding/re-encoding." (Default)
         - **Rendered Export / Transcoded Derivative (OSD)**: "Burns camera name and timestamp onto video (transcoded derivative, takes longer)."
       - Form controls:
         - Start Date/Time picker & End Date/Time picker.
         - Quick presets: "Last 5 min", "Last 15 min", "Timeline Selection".
       - Workflow & State Machine:
         - Submits to `POST /api/recordings/export` with `{ cameraId, startTime, endTime, exportMode }`.
         - Polls `GET /api/recordings/export/:id` while status is `QUEUED` or `RUNNING`.
         - On `COMPLETED`: Displays file size, **"SHA-256 integrity checksum"** badge (with copy button), and direct "Download MP4" button pointing to `/api/recordings/export/:id/download`.
         - On `FAILED`: Displays clean error message. If `errorCode === 'INCOMPATIBLE_SEGMENTS'`, shows explanation: "Cannot use stream copy because recording segments have differing video formats/codecs. Try selecting a tighter range or transcoding."
       - Palette 1 styling: Dark Obsidian `#090d16` background, Slate `#111827` cards, Ion Blue `#4fc3f7` accents, high contrast typography.
  </action>
  <verify>
    Run `npx tsc --project client/tsconfig.json` to verify compilation.
  </verify>
</task>
