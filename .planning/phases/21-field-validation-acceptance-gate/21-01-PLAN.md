# Plan 21-01: Field Validation & 72-Hour Acceptance Gate

## Goal
Deliver the automated 72-hour unattended soak test simulation, network glitch resilience harness, motion buffer promotion verification, evidence package validation, and installer litmus deployment test suite for Day 75 MVP scope freeze.

## Implementation Details

### Task 1: Accelerated 72-Hour Soak & Network Glitch Acceptance Suite (`tests/soak-acceptance.test.ts`)
- Model a fleet of 16 cameras in Fastify test app.
- Simulate continuous segment ingest across 8 cameras over an accelerated 72-hour timeline (e.g. 72 virtual hour ticks), adding video segments to `recordings` database.
- Create incident bookmarks on key segments and trigger storage FIFO rollover at 85% capacity threshold. Verify older unbookmarked segments are purged while bookmarked segments are strictly preserved.
- Simulate network glitch on Camera 3 (pulling cable):
  - Health check ping fails -> status becomes `DEGRADED`.
  - Advance time past 30s hysteresis threshold -> status transitions to `OFFLINE`.
  - Emits `camera.offline` event and triggers SMTP email alert dispatcher.
- Simulate network reconnection on Camera 3:
  - Health check recovers -> status transitions to `ONLINE`.
  - Emits `camera.online` event containing calculated downtime duration.
  - Assert zero listener leaks on EventEmitter.
- Trigger native motion on Camera 10:
  - 10s pre-buffer segments promoted to permanent database catalog.
  - 30s post-buffer active recording window honored.
- Export evidence package for Camera 10:
  - Download `.zip` bundle via `/api/recordings/export/:id/bundle`.
  - Unpack and execute `node verify.js` via `child_process.execFile` and assert exit code 0 and `INTEGRITY VERIFIED`.
  - Mutate one byte in video file and verify `node verify.js` fails with exit code 1 and `TAMPER DETECTED`.
