# Plan 19-01: Built-in SMTP Email Alerting Engine & API

## Objective
Implement an in-process, zero-external-dependency RFC 5321 SMTP client using Node's standard `node:net` and `node:tls` libraries. Connect it to the `EventBus` for `motion.detected`, `camera.offline`, and `storage.warning` alerts, apply token-bucket rate limiting, format high-contrast IST HTML email templates with playback deep-links, add `core.email_alerts` to Core licensing baseline, and expose authenticated REST endpoints (`GET /api/notifications/smtp`, `PUT /api/notifications/smtp`, `POST /api/notifications/smtp/test`).

## Tasks

1. **Core Capability Realignment (`src/licensing/types.ts`)**:
   - Add `'core.email_alerts'` to `CORE_CAPABILITIES` so that basic email alerts are available in Core (Package 1).
2. **RFC 5321 SMTP Transport Client (`src/notifications/smtp-client.ts`)**:
   - Built with `node:net` and `node:tls`.
   - Supports:
     - Direct TLS (port 465) or plain socket with STARTTLS upgrade (port 587/25).
     - Standard SMTP handshake: `220` → `EHLO` → `STARTTLS` → `AUTH LOGIN` (or `AUTH PLAIN`) → `MAIL FROM` → `RCPT TO` → `DATA` → `QUIT`.
     - 10-second timeout handling and clean socket destruction on error.
     - Custom transport injection interface `ISmtpTransport` for unit testing without external network access.
3. **SMTP Alert Dispatcher Service (`src/notifications/smtp-dispatcher.service.ts`)**:
   - Manages SMTP configuration state: host, port, secure, requireTls, user, pass, from, recipients, cooldownSeconds, events, enabled.
   - Generates responsive HTML email with IST timestamp, incident severity badges, camera info, and timeline deep-link.
   - Listens to `EventBus` on `motion.detected`, `camera.offline`, `storage.warning`.
   - Protects from flood with `TokenBucketRateLimiter` per `${cameraId}:${eventType}`.
4. **REST API Endpoints (`src/notifications/notification.routes.ts`)**:
   - `GET /api/notifications/smtp`: Returns configuration with masked password (`********`).
   - `PUT /api/notifications/smtp`: Updates configuration; preserves existing password if masked placeholder is passed.
   - `POST /api/notifications/smtp/test`: Sends an immediate test email and returns delivery receipt or error message.
5. **Unit & Integration Test Suite (`tests/smtp-alerts.test.ts`)**:
   - Mock SMTP transport validating command sequences and MIME headers.
   - Rate limiting cooldown verification.
   - HTML template IST timestamp and deep-link generation.
   - Fastify route integration (unauthorized 401, non-admin 403, admin 200).
