<threat_model>
<threat>
T-02-04: License entitlement bypass via direct API camera creation
Severity: high
Mitigation: CameraService and camera routes strictly check `request.server.capabilities.getCameraLimit()` against existing camera count before persisting any new camera to the database.
</threat>
<threat>
T-02-05: Unauthorized camera reconfiguration by Viewer role
Severity: high
Mitigation: Protect all write endpoints (`/discover`, `POST /cameras`, `DELETE /cameras/:id`) with `requireRole([Role.ADMIN])`. Viewers can only view existing camera listings.
</threat>
<threat>
T-02-06: Sensitive camera credentials leakage in API responses
Severity: medium
Mitigation: CameraResponseDto and serialization explicitly omit raw camera passwords from GET `/api/cameras` and GET `/api/cameras/:id`.
</threat>
</threat_model>

  <action>
    - Create `src/cameras/camera.types.ts`:
      - `OnboardCameraSchema`: ip, port, username, password, name
      - `ManualCameraSchema`: name, rtspUrl, subStreamUrl?
      - `CameraResponseDto`: sanitizes output, omitting password
    - Create `src/cameras/camera.service.ts`:
      - Injects `ICameraProvider`, `MediaMtxClient`, `EventBus`, and `PrismaClient`.
      - `discover(timeoutMs)`: calls provider discovery.
      - `onboardOnvifCamera(input, cameraLimit)`:
        - Checks `count() < cameraLimit`; throws `LicenseLimitExceededError` if exceeded.
        - Resolves profiles via `CameraProvider.getProfiles()`.
        - Selects main stream and sub-stream (if present).
        - Generates sanitized `mediaMtxPath` (e.g. `cam_<uuid_slug>`).
        - Saves to PostgreSQL `cameras` table.
        - Calls `mediaMtxClient.addPath(mediaMtxPath, rtspUrl)`.
        - Emits `camera.online` lifecycle event to `eventBus`.
      - `onboardManualCamera(input, cameraLimit)`:
        - Validates RTSP URI format.
        - Checks `count() < cameraLimit`.
        - Provisions MediaMTX path and saves to DB.
        - Emits `camera.online` event.
      - `removeCamera(id)`:
        - Deletes MediaMTX path via `mediaMtxClient.removePath(mediaMtxPath)`.
        - Deletes camera record in DB.
        - Emits `camera.offline` lifecycle event.
    - Create `tests/camera-discovery.test.ts` verifying service methods, license limit checks, and mock provider interactions.
  </action>
