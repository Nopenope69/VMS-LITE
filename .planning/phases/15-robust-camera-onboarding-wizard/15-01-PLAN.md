# Plan 15-01: Backend Probe Endpoints & Transactional Onboarding Service

## Objective
Implement backend verification APIs that enable a step-by-step camera onboarding pipeline: network reachability handshake, credential and stream profile probe, temporary MediaMTX preview provisioning with readiness polling, and atomic database commit with rollback.

## Tasks

1. **CameraService Probe & Transaction Methods**:
   - `probeNetwork(ip: string, port = 554, timeoutMs = 2500)`:
     - Uses `net.createConnection` to test TCP connectivity to `ip:port`.
     - Measures latency in milliseconds.
     - Returns `{ reachable: boolean, latencyMs: number | null, error?: string }`.
   - `probeAuthAndProfiles(params: { ip: string; port?: number; username?: string; password?: string; xaddr?: string })`:
     - Queries ONVIF device information (`getDeviceInformation`).
     - Queries video stream profiles (`getProfiles`).
     - Tags `isMainStream` (highest resolution / profile[0]) and sub-stream (lower resolution).
     - Returns `{ authenticated: boolean, device: {...}, profiles: [...] }`.
   - `provisionPreviewPath(rtspUrl: string)`:
     - Creates temporary preview path `preview_<randomId>`.
     - Polls MediaMTX up to 5s for `ready: true`.
     - Returns `{ pathName: string, ready: boolean, whepUrl: string }`.
   - `teardownPreviewPath(pathName: string)`:
     - Removes temporary preview path from MediaMTX.
   - `commitVerifiedCamera(input: CommitCameraInput, cameraLimit: number)`:
     - Checks license limits.
     - Commits camera record to PostgreSQL.
     - Finalizes permanent MediaMTX path.
     - Emits `camera.online` event.
     - Cleans up preview path if provided.
     - Rolls back MediaMTX path if database save fails.

2. **Camera Routes Extension**:
   - Add `POST /api/cameras/probe-network` (Admin & Operator).
   - Add `POST /api/cameras/probe-auth` (Admin only).
   - Add `POST /api/cameras/provision-preview` (Admin only).
   - Add `POST /api/cameras/teardown-preview` (Admin only).
   - Add `POST /api/cameras/commit` (Admin only).

3. **Automated Integration Tests**:
   - Create `tests/camera-onboarding-wizard.test.ts`:
     - Test TCP probe against loopback / mock server.
     - Test ONVIF auth & profile probe.
     - Test preview path provisioning and teardown.
     - Test atomic commit and license limit enforcement.
