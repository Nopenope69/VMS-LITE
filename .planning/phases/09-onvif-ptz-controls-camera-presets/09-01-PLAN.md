<threat_model>
### ASVS L1 Threat Model: PTZ Controls & Camera Presets
- **T-09-01 (Unbounded PTZ Movement / Camera Runaway)**: If the client drops offline, closes browser tab, or network latency spikes during continuous move, the camera continues moving until physical stop or motor failure.
  - *Mitigation*: `PtzService` sets an active 1500ms server-side timeout on every move command; auto-executes `ptzStop()` when the timer expires.
- **T-09-02 (Surveillance Tampering / Unauthorized Movement)**: Unprivileged users (Viewers or operators without `canControlPtz`) drive cameras away from critical security perimeters.
  - *Mitigation*: Gated strictly by `requireCameraPermission('canControlPtz')` and `requireCapability('extended.ptz')`. Viewers receive 403.
- **T-09-03 (Velocity Injection & Boundary Tampering)**: Malformed velocity floats (`NaN`, `Infinity`, values outside [-1.0, 1.0]) cause ONVIF SOAP errors or device driver crashes.
  - *Mitigation*: Zod schema validates and clamps `x`, `y`, and `z` between `-1.0` and `1.0`.
</threat_model>

<task type="auto" name="ptz-service-watchdog">
  <action>
    1. Create `src/ptz/ptz.service.ts`:
       - Class `PtzService` taking optional `ICameraProvider` (defaults to `onvifCameraProvider`).
       - Maintain `activeWatchdogs: Map<string, NodeJS.Timeout>`.
       - Implement `move(cameraId: string, speed: { x?: number; y?: number; z?: number })`:
         - Retrieve camera details from `prisma.camera.findUnique({ where: { id: cameraId } })`.
         - If camera does not exist, throw NotFound error.
         - If existing watchdog exists for `cameraId`, clear it.
         - Invoke `provider.ptzMove(connectionParams, { speed })`.
         - Set a 1500ms watchdog timer:
           ```typescript
           const timer = setTimeout(async () => {
             try {
               await this.stop(cameraId);
             } catch (err) {
               // Log watchdog auto-stop error
             } finally {
               this.activeWatchdogs.delete(cameraId);
             }
           }, 1500);
           this.activeWatchdogs.set(cameraId, timer);
           ```
       - Implement `stop(cameraId: string)`:
         - Clear and delete any active watchdog timer for `cameraId`.
         - Invoke `provider.ptzStop(connectionParams)`.
       - Implement `getPresets(cameraId: string)`: returns `CameraPreset[]`.
       - Implement `gotoPreset(cameraId: string, presetToken: string)`: drives camera to target preset.
       - Implement `setPreset(cameraId: string, presetName: string)`: saves preset and returns token.
       - Implement `removePreset(cameraId: string, presetToken: string)`: removes preset.
       - Export singleton `ptzService`.
  </action>
  <verify>
    Run `npx tsc --noEmit` to verify type safety.
  </verify>
</task>
