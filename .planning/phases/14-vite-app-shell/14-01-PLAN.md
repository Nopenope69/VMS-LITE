# Plan 14-01: Vite Toolchain & Unified Operator App Shell

## Objective
Establish the client bundler toolchain (`client/index.html`, `client/vite.config.ts`, `client/src/main.tsx`) and construct a unified `App.tsx` shell providing authentication gating, a persistent header with live clock and user status, a collapsible sidebar, and full routing for Dashboard, Live View, Playback, Cameras, Events & Alerts, and Settings.

## Tasks

1. **Package Scripts & Dependencies**:
   - In `package.json`, ensure `vite` is in `devDependencies`.
   - Add `"build:client": "vite build --config client/vite.config.ts"` and `"dev:client": "vite --config client/vite.config.ts"` to `scripts`.

2. **Vite Toolchain Setup**:
   - Create `client/index.html`:
     - Clean modern layout, title "Basic VMS", viewport meta tags, dark mode background `#0f172a`.
     - Mounts `<div id="root"></div>` and scripts `/src/main.tsx`.
   - Create `client/vite.config.ts`:
     - Configures `@vitejs/plugin-react`.
     - Sets build `outDir` to `client/dist` (relative to client root) and emptyOutDir: true.
     - Sets development server proxy:
       - `/api` -> `http://localhost:3000`
       - `/ws` -> `ws://localhost:3000` with `ws: true`
   - Create `client/src/main.tsx`:
     - Imports `React`, `ReactDOM/client`, `AuthProvider`, and `App`.
     - Mounts the application to `#root`.

3. **Unified App Shell (`client/src/App.tsx`)**:
   - Implement `App.tsx` using `useAuth()`:
     - **Unauthenticated State**:
       - Render a dedicated, high-contrast CCTV Login view.
       - Form with username, password, submit button, error messaging, and default credential reminder.
     - **Authenticated State**:
       - **Top Navigation Bar**:
         - Basic VMS branding with CCTV camera icon.
         - Real-time digital clock (updating every second, displaying date & local/IST time).
         - Active user badge with role chip (`ADMIN`, `OPERATOR`, `VIEWER`).
         - Notification drawer toggle with unread motion alert counter badge.
         - Logout button.
       - **Collapsible Sidebar**:
         - Navigation items:
           1. `Dashboard` (LayoutDashboard icon)
           2. `Live View` (Video icon)
           3. `Playback` (Film / History icon)
           4. `Cameras` (CCTV / Camera icon)
           5. `Events & Alerts` (Bell / AlertTriangle icon)
           6. `Settings` (Settings icon)
         - Collapse / expand toggle button with tooltips.
       - **Active View Rendering**:
         - `dashboard`: Quick stats cards (total cameras, online, degraded, storage percentage gauge), camera status summary, recent alerts ticker, quick-action navigation buttons.
         - `live`: Mounts `LiveViewPage`.
         - `playback`: Mounts `PlaybackPage`.
         - `cameras`: Camera roster with online/degraded/offline indicators from `useCameraHealth()`, latency/bitrate info, stream link previews, and "Add Camera" button.
         - `events`: Filterable event log with severity filtering (`info`, `warning`, `critical`), camera filter, and incident bookmarks.
         - `settings`: Overview of recording modes (Continuous, Motion, Scheduled), storage quota status, buttons to launch `NotificationSettingsModal` and `UserManagementModal` (admin only), and license capability summary.

4. **Refine `useCameraHealth.ts`**:
   - Check `localStorage.getItem('vms_token') || localStorage.getItem('token')` for seamless authentication with `AuthContext`.

## Verification
- Run `npm run build:client` and verify `client/dist` is populated with `index.html` and bundled assets.
- Run `npx tsc --project client/tsconfig.json` and ensure 0 TypeScript errors.
