# Plan 18-02: Operator Landing Dashboard

## Objective
Deliver a unified system overview landing dashboard for operators and business owners, backed by a dedicated `GET /api/system/dashboard` endpoint summarizing real-time camera fleet health, active recording engines vs motion buffer standby, storage pool capacity and estimated retention, node uptime, and recent security alerts.

## Tasks

1. **Backend System Dashboard API (`src/system/system.routes.ts`)**:
   - `GET /api/system/dashboard`:
     - Requires authentication (`authenticate`).
     - Aggregates:
       - `status`: Overall node health status (`HEALTHY`, `DEGRADED`, or `CRITICAL`).
       - `uptimeSeconds`: Seconds since server boot.
       - `fleet`: Camera counts by health status (`online`, `degraded`, `offline`, `unknown`, `total`).
       - `recording`: Recording engine modes breakdown (`continuous`, `motionOnly`, `scheduled`, `paused`, `total`).
       - `storage`: Storage metrics (`totalBytes`, `usedBytes`, `freeBytes`, `usedPercent`, `retentionDays`, `estimatedDaysRemaining`, `autoPurgeThresholdPercent`).
       - `recentEvents`: Latest 10 events from PostgreSQL / EventBus.
       - `licensing`: Edition, active camera limit, expiration status.
   - Register route plugin in `src/server.ts` with prefix `/api/system`.

2. **Frontend Dashboard UI (`client/src/components/DashboardView.tsx`)**:
   - High-contrast, clean status banner with system health and uptime badge.
   - 3-column metric cards:
     1. **Camera Fleet**: Count breakdown with colored indicators (Online green, Degraded yellow, Offline red).
     2. **Recording Fleet**: Active continuous count vs motion ring buffer standby.
     3. **Storage Retention**: Used/total bar gauge, estimated days remaining, and auto-purge threshold.
   - **Recent Events & Alerts Table**: Last 24h event feed with timestamp, source, camera ID, severity badge, and direct shortcut link to Playback.
   - **Quick Actions**: "Launch Live Grid", "Search 24h Playback", "Camera Roster", "Operational Settings".
   - Integrated into `App.tsx` replacing inline static cards.

3. **Backend Integration Test Suite (`tests/system-dashboard.test.ts`)**:
   - Tests `GET /api/system/dashboard`:
     - 401 when unauthorized.
     - 200 with complete fleet, recording, and storage metrics when authenticated.
