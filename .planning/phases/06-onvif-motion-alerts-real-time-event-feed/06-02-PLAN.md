<threat_model>
<threat>
T-06-03: Unauthorized WebSocket eavesdropping on camera motion events
Severity: high
Mitigation: Enforce JWT authentication on WebSocket upgrade handshake (?token=... or Authorization header); disconnect unauthorized sockets immediately.
</threat>
<threat>
T-06-04: Slow consumer / socket buffer memory leak
Severity: medium
Mitigation: Limit WebSocket client send buffer; drop slow consumers exceeding bufferedAmount threshold.
</threat>
</threat_model>

      - Attach `webSocketFeedService` to Fastify HTTP server.
