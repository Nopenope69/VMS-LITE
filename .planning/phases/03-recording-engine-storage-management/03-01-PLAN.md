<objective>
Configure fMP4 segment recording metadata cataloging, implement the webhook handler for MediaMTX `runOnRecordSegmentComplete`, and provide recording timeline query endpoints.

Purpose: Enable zero-transcode packet-preserving recording in fMP4 format (REC-01) and automatically catalog completed video segments into PostgreSQL with start/end timestamps and file sizes (REC-03).
Output: Prisma schema update, `RecordingService`, `recordingRoutes`, and unit/integration test suite.
</objective>

<threat_model>
<threat>
T-03-01: Arbitrary file path injection via segment completion webhook
Severity: high
Mitigation: SegmentCompleteWebhookSchema strictly validates that segmentPath stays within configured recording directories, preventing directory traversal attacks (e.g., ../../etc/passwd).
</threat>
<threat>
T-03-02: Forged segment notifications from unauthorized clients
Severity: medium
Mitigation: Secure the webhook endpoint with shared webhook secret or restrict access to localhost/internal subnet where MediaMTX operates.
</threat>
<threat>
T-03-03: BigInt JSON serialization crash in API responses
Severity: medium
Mitigation: Ensure sizeBytes (BigInt) is safely converted to number or string in Recording DTO serialization.
</threat>
</threat_model>

  <files>prisma/schema.prisma</files>
  <action>
    - Update `prisma/schema.prisma` with:
      - `model Recording`:
        - `id`: String @id @default(uuid())
        - `cameraId`: String @map("camera_id")
        - `camera`: Camera relation
        - `mediaMtxPath`: String @map("mediamtx_path")
        - `filePath`: String @map("file_path")
        - `fileName`: String @map("file_name")
        - `startTime`: DateTime @map("start_time")
        - `endTime`: DateTime @map("end_time")
        - `duration`: Float
        - `sizeBytes`: BigInt @map("size_bytes")
        - `format`: String @default("fmp4")
        - `createdAt`: DateTime @default(now()) @map("created_at")
        - Indexes on `[cameraId, startTime]` and `[startTime]`
        - Mapping: `@@map("recordings")`
      - `model RecordingSchedule`:
        - `id`: String @id @default(uuid())
        - `cameraId`: String @map("camera_id")
        - `camera`: Camera relation
        - `dayOfWeek`: Int (0-6)
        - `startHour`: Int (0-23)
        - `startMin`: Int (0-59)
        - `endHour`: Int (0-23)
        - `endMin`: Int (0-59)
        - `createdAt`: DateTime @default(now()) @map("created_at")
        - `updatedAt`: DateTime @updatedAt @map("updated_at")
        - Index on `[cameraId, dayOfWeek]`
        - Mapping: `@@map("recording_schedules")`
      - Add `recordings Recording[]` and `schedules RecordingSchedule[]` relation fields to `model Camera`.
    - Run `npx prisma generate` to recompile Prisma client.
