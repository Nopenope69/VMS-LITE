<threat_model>
<threat>
T-01-03: License token forgery or modification
Severity: high
Mitigation: Cryptographically verify signature using Ed25519 with `@noble/ed25519`. Reject tokens where header, payload, or signature do not match the trusted public key.
</threat>
<threat>
T-01-04: Expired or replay license utilization
Severity: high
Mitigation: Check `expiresAt` timestamp against current system clock; invalidate capability queries if license has expired. Fall back gracefully to minimal evaluation mode.
</threat>
<threat>
T-01-05: Domain logic pollution with tier checks
Severity: high
Mitigation: Expose ONLY `capabilities.has(capabilityName)` and `capabilities.getCameraLimit()`. Never expose raw tier names (e.g. "PRO", "ENTERPRISE") to controller logic.
</threat>
</threat_model>
