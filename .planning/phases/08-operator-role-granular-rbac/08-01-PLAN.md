<objective>
Implement the backend foundation for 3-tier RBAC (`ADMIN`, `OPERATOR`, `VIEWER`) and per-camera permission ACLs (`canViewLive`, `canViewPlayback`, `canControlPtz`, `canExportClips`).

Purpose: Allow commercial installations to grant guards/operators live and playback access to specific cameras while strictly locking out system configuration and unauthorized camera feeds.
Output: Updated Prisma schema, generated client, ACL guard hooks, permission management API, and comprehensive test suite.
</objective>

<task type="auto" name="schema-and-migration">
  <action>
    1. Update `prisma/schema.prisma`:
       - Add `OPERATOR` to `enum Role { ADMIN, OPERATOR, VIEWER }`.
       - Add `cameraPermissions CameraPermission[]` relation to `model User`.
       - Add `cameraPermissions CameraPermission[]` relation to `model Camera`.
       - Add `model CameraPermission` with fields:
         `id`, `userId`, `user`, `cameraId`, `camera`, `canViewLive`, `canViewPlayback`, `canControlPtz`, `canExportClips`, `createdAt`, `updatedAt`, and unique constraint `@@unique([userId, cameraId])`.
    2. Run `npx prisma generate` to re-generate the Prisma client types.
  </action>
  <verify>
    Run `npx prisma validate` to confirm schema validity.
  </verify>
</task>

<task type="auto" name="acl-guard-and-services">
  <action>
    1. Extend `src/users/rbac.guard.ts`:
       - Update `requireRole` to handle `Role.OPERATOR`.
       - Add `requireCameraPermission(permission: 'canViewLive' | 'canViewPlayback' | 'canControlPtz' | 'canExportClips')`:
         - If user is `ADMIN`: allow bypass.
         - If user is `VIEWER`: allow `canViewLive` and `canViewPlayback` across all cameras; deny mutation or control permissions with 403.
         - If user is `OPERATOR`: look up `CameraPermission` for `request.params.id || request.params.cameraId`. If record missing or permission flag is false, return HTTP 403 Forbidden.
    2. Extend `src/users/auth.service.ts`:
       - Add `listUsers()`: returns user list without password hashes.
       - Add `setUserPermissions(userId: string, permissions: Array<{ cameraId: string; canViewLive?: boolean; canViewPlayback?: boolean; canControlPtz?: boolean; canExportClips?: boolean }>)`.
       - Add `getUserPermissions(userId: string)`: returns all configured permissions for a user.
    3. Update `src/users/auth.routes.ts`:
       - `GET /api/auth/users`: Admin only, lists all users.
       - `GET /api/auth/users/:id/permissions`: Admin or self, returns user's camera permissions.
       - `PUT /api/auth/users/:id/permissions`: Admin only, gated by `requireCapability('extended.operator_role')`, sets operator's camera permissions.
       - `POST /api/auth/users`: when creating user with `role === 'OPERATOR'`, require `extended.operator_role` capability.
  </action>
  <verify>
    Run `npx tsc --noEmit` to verify type safety.
  </verify>
</task>

<task type="auto" name="camera-route-filtering-and-tests">
  <action>
    1. Update `src/cameras/camera.routes.ts`:
       - In `GET /api/cameras`: if user is `OPERATOR`, query their permissions and return only cameras where `canViewLive === true || canViewPlayback === true`.
       - In `GET /api/cameras/:id`: add `preHandler: [authenticate, requireCameraPermission('canViewLive')]`.
       - Ensure `POST /api/cameras`, `DELETE /api/cameras/:id`, and `POST /api/cameras/discover` remain strictly `requireRole([Role.ADMIN])`.
    2. Create `tests/operator-rbac.test.ts`:
       - Test that creating an `OPERATOR` without `extended.operator_role` returns 403.
       - Test that creating an `OPERATOR` with `extended.operator_role` succeeds.
       - Test that an `OPERATOR` only sees permitted cameras in `GET /api/cameras`.
       - Test that an `OPERATOR` attempting to access an unpermitted camera receives 403.
       - Test that an `OPERATOR` attempting to delete a camera receives 403.
       - Test that an `ADMIN` retains full access across all endpoints.
  </action>
  <verify>
    Run `npm test tests/operator-rbac.test.ts` to confirm all test cases pass.
  </verify>
</task>
