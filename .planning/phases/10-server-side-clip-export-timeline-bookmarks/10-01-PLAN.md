<threat_model>
### ASVS L1 Threat Model: Clip Export & Bookmarks
- **T-10-01 (CPU Starvation via Unthrottled Re-Encoding)**: Operators requesting large exports trigger heavy video transcoding, starving CPU resources needed by live WebRTC streams and camera ingest.
  - *Mitigation*: Default to zero-transcode stream copy (`-c copy`); throttle concurrent OSD transcode jobs to 1; execute at low CPU priority.
- **T-10-02 (Storage Saturation from Export Artifacts)**: Large MP4 files abandoned in export directories fill system storage and crash database logging.
  - *Mitigation*: Enforce strict 48-hour TTL with automated hourly cleanup; link export storage into `StorageController` quota monitoring.
- **T-10-03 (Unauthorized Evidence Export & Tampering)**: Unprivileged viewers or malicious users download unauthorized camera footage.
  - *Mitigation*: Gated by `requireCapability('extended.clip_export')` and `requireCameraPermission('canExportClips')`. Computes SHA-256 checksum for tamper-evidence.
</threat_model>

<task type="auto" name="export-service-and-ttl-pruner">
  <action>
    1. Create `src/export/export.service.ts`:
       - Class `ExportService` managing clip generation and disk cache:
         - `createExport(params: { cameraId: string; userId?: string; startTime: Date; endTime: Date; includeOsd?: boolean })`:
           - Query `prisma.recording` for overlapping segments.
           - If no segments found, throw error `No recordings found for requested range`.
           - Create `ExportJob` with status `'processing'` and `expiresAt = new Date(Date.now() + 48 * 3600 * 1000)`.
           - In mockMode or test: simulate output file creation and SHA-256 hash.
           - In real mode: create concat file, spawn `ffmpeg` child process with `-c copy` (or `drawtext` filter if `includeOsd: true`).
           - Compute SHA-256 hash of output file.
           - Update `ExportJob` with status `'completed'`, `filePath`, `fileSize`, and `sha256`.
         - `getExportJob(id: string)`: returns `ExportJob`.
         - `pruneExpiredExports()`: finds all jobs where `expiresAt <= new Date()`, unlinks files from disk, and marks status `'expired'`.
         - Export singleton `exportService`.
  </action>
