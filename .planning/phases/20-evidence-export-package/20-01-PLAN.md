# Plan 20-01: Self-Verifying Evidence Export Package

## Objective
Implement an automated, zero-external-dependency evidence packaging engine that bundles exported incident video into a signed `.zip` package containing `video.mp4`, cryptographic `manifest.json`, user audit trail `audit.json`, and a standalone `verify.js` Node.js script. Expose `GET /api/recordings/export/:id/bundle` and update the UI in `ClipExportModal.tsx`.

## Tasks

1. **Zero-Dependency ZIP Builder (`src/export/zip-builder.ts`)**:
   - Standard PKWARE ZIP archive writer using Node.js built-in `node:zlib` (`zlib.crc32`).
   - Supports in-memory or streamed file entries without external npm packages.
2. **Evidence Bundle Service (`src/export/evidence-bundle.service.ts`)**:
   - `buildEvidenceBundle(exportId: string, clientIp?: string): Promise<{ buffer: Buffer; filename: string }>`:
     - Reads completed export job and source `video.mp4`.
     - Loads camera details and active timeline bookmarks within the clip window from PostgreSQL.
     - Formats `manifest.json` with file sizes and SHA-256 hashes.
     - Formats `audit.json` with requester identity, timestamp (ISO + IST), client IP, and node environment.
     - Embeds portable `verify.js` script with SHA-256 validation logic.
     - Archives entries into `EVIDENCE_EXPORT_{exportId}_{timestamp}.zip`.
3. **REST API Endpoint (`src/export/export.routes.ts`)**:
   - `GET /api/recordings/export/:id/bundle`:
     - Gated by `authenticate` and `requireCapability('extended.clip_export')`.
     - Sets headers `Content-Type: application/zip`, `Content-Disposition: attachment; filename="EVIDENCE_EXPORT_{exportId}_{timestamp}.zip"`, and `X-Checksum-SHA256`.
     - Returns bundle buffer.
4. **Operator Frontend UI (`client/src/components/ClipExportModal.tsx`)**:
   - Add "Download Evidence Package (.ZIP)" primary action button upon job completion.
   - Display evidence breakdown pill: "Signed Bundle: video.mp4 + manifest.json + audit.json + verify.js".
5. **Integration Test Suite (`tests/evidence-bundle.test.ts`)**:
   - Tests valid ZIP generation and verifies contents with system unzipper.
   - Executes `verify.js` via `child_process.spawn('node', ['verify.js'])` on authentic export (asserts exit code 0).
   - Tests tamper detection: modifies 1 byte in `video.mp4` and runs `verify.js` (asserts exit code 1 and TAMPER error).
   - Tests Fastify endpoint `GET /api/recordings/export/:id/bundle`.
