# Plan 14-02: Canonical Production Serving & Static Fallback

## Objective
Configure production serving architecture: implement `@fastify/static` with Single Page Application (SPA) fallback in `src/server.ts` so Fastify can serve the frontend directly in single-container mode, create the canonical edge `Caddyfile` for full appliance deployments, and implement an automated integration test verifying serving behavior.

## Tasks

1. **Canonical Appliance Ingress (`Caddyfile`)**:
   - Create root `Caddyfile`:
     - Ingress listening on port 80 (and optional TLS).
     - Static file root set to `./client/dist` with `file_server` and `try_files {path} /index.html`.
     - Reverse proxy for `/api/*` and `/ws` to Fastify (`127.0.0.1:3000`).
     - Reverse proxy for `/whep/*` and `/hls/*` directly to MediaMTX (`127.0.0.1:8889`).
     - Compression (`encode gzip zstd`) and standard security headers.

2. **Fastify Static Serving & SPA Fallback (`src/server.ts`)**:
   - Check if `client/dist` exists on startup using `fs.existsSync`.
   - If present, register `@fastify/static` serving `client/dist` with `prefix: '/'`.
   - Implement `setNotFoundHandler`:
     - If the request path begins with `/api/`, return standard HTTP 404 JSON (`{ error: 'NotFound', message: 'Route not found' }`).
     - If the request is a web page request (does not start with `/api/`), serve `client/dist/index.html` to support client-side routing.

3. **Automated Integration Test (`tests/production-serving.test.ts`)**:
   - Verify that:
     1. `GET /` returns HTTP 200 with HTML content from `client/dist/index.html`.
     2. `GET /live` returns HTTP 200 with HTML content (SPA routing fallback).
     3. `GET /health` continues to return HTTP 200 with JSON `{ status: 'ok', service: 'basic-vms' }`.
     4. `GET /api/unknown-endpoint` returns HTTP 404 with JSON error, confirming API routes are not accidentally swallowed by the SPA fallback.

4. **Full Test Suite & Compliance**:
   - Run `npm test` ensuring all tests pass.
   - Run `npm run audit:licenses` ensuring 100% permissive licensing.
