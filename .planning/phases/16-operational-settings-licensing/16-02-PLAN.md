# Plan 16-02: Frontend Operational Settings Component & UI Integration

## Objective
Build a comprehensive operational settings component (`OperationalSettingsModal.tsx` and Settings view integration) giving operators visual control over recording modes, an interactive 7-day hourly schedule grid, storage retention dropdown with pool usage gauge, and commercial license verification summary.

## Tasks

1. **Build `OperationalSettingsModal.tsx`**:
   - Tabbed / Sectioned interface:
     - **Recording Mode Selection**:
       - Cards for `24/7 Continuous`, `Motion Only (Ring Buffer)`, `Scheduled (Grid)`, `Manual Off`.
       - Mode explanation & camera targeting selector (All Cameras vs Single Camera).
     - **Interactive 7-Day Weekly Schedule Grid**:
       - 7 rows (Sunday to Saturday), 24 columns (00:00 to 23:00).
       - Click or drag-to-paint 1-hour slots (active = green, idle = dark slate).
       - Quick presets: "24/7 All Hours", "Business Hours (M-F 9AM-6PM)", "Nights & Weekends", "Clear All".
     - **Storage & Retention Pool**:
       - Retention period selector (`7 Days`, `15 Days`, `30 Days`, `60 Days`, `Custom`, `Full Disk FIFO`).
       - Disk usage meter (Used vs Free vs Warning/Critical thresholds).
       - Estimated retention days remaining calculation.
       - "Purge Storage Now" action button with confirmation dialog and result message.
     - **Commercial Licensing Status**:
       - Displays Edition, Verified capabilities list, and highlight badge: `Camera Health Telemetry: Included in Core`.
       - Shows active camera limit (e.g. 16 cameras for Core).

2. **Integrate into `client/src/App.tsx`**:
   - Replace static placeholders in Settings view with interactive `OperationalSettingsModal` launcher and status summaries.
   - Wire API integration (`GET /api/settings/operational`, `PUT /api/settings/operational`, `POST /api/settings/storage/purge`).
   - Export component in `client/src/index.ts`.

3. **Verification**:
   - `npm run build:client` passes with zero errors.
   - `npm run build` root project compiles cleanly.
   - Verify all tests pass with zero regressions.
