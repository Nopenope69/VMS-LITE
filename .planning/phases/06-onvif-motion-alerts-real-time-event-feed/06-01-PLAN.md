Mitigation: Use strict regex / safe DOM parsing without external entity resolution or schema dtd loading.
</threat>

  <action>
    - Create `src/events/onvif-events.service.ts`:
      - `OnvifEventListenerService` class injecting `EventBus` and `CameraService`.
      - `subscribeCamera(camera)`:
        - Creates PullPoint subscription (`CreatePullPointSubscription`).
        - Saves subscription reference address.
        - Starts polling worker (`pollPullMessages`).
      - `unsubscribeCamera(cameraId)`: terminates active subscription and stops polling worker.
      - `parseSoapNotification(xml)`:
        - Safe parser extracting Topic and Data/SimpleItem name/value pairs (`IsMotion`, `State`, etc.).
        - Ignores external entities (mitigating T-06-02).
      - On motion detected:
        - Emits `CoreEventType.MOTION_DETECTED` (`motion.detected`) to `eventBus` (`EVT-04`).
        - Sets `severity: 'warning'`.
      - Implements mock mode for tests (`mockMode: boolean`) to simulate camera triggers deterministically.
  </action>
