# Plan 18-01: Operator Live Controls

## Objective
Equip security operators with high-utility daily live controls: instant frame snapshot download via HTML5 `<canvas>`, multi-grid kiosk fullscreen mode for dedicated guard stations, and client-side CSS digital zoom (1x to 4x) with click-and-drag pan without server transcoding.

## Tasks

1. **Snapshot Utility (`client/src/utils/snapshot.ts`)**:
   - `captureVideoSnapshot(videoElement: HTMLVideoElement, cameraName: string): boolean`
   - Draws current frame to in-memory `<canvas>` matching video resolution.
   - Generates JPEG blob (`quality: 0.95`).
   - Generates download filename: `snapshot_{cameraName}_{YYYY-MM-DD_HH-mm-ss}.jpg`.
   - Programmatically triggers browser anchor download.

2. **Client-Side Digital Zoom & Pan (`client/src/components/WhepHlsPlayer.tsx` or `LiveCameraTile.tsx`)**:
   - Implement zoom state: `zoomScale` (1.0 to 4.0 in 0.25x steps) and `panOffset` `{ x, y }`.
   - Wheel event handler:
     - Delta up increments zoom; delta down decrements zoom.
     - When zoom is 1.0x, pan resets to (0, 0).
   - Mouse drag handler:
     - When zoom > 1.0x, `onMouseDown`, `onMouseMove`, `onMouseUp` updates `panOffset`.
     - Clamps pan translation within viewport boundaries.
   - Zoom controls overlay or quick indicator:
     - Shows current zoom badge (e.g. `2.5x`) with reset button when zoom > 1.0x.
     - CSS transform: `transform: scale(${zoomScale}) translate(${panOffset.x}px, ${panOffset.y}px); transform-origin: center center;`.

3. **Tile Snapshot Button & Header Controls (`client/src/components/LiveCameraTile.tsx`)**:
   - Add Camera Snapshot icon button (`Camera` icon from `lucide-react`) in tile header.
   - Invokes `captureVideoSnapshot` on the tile's active `<video>` element.
   - Shows brief success feedback tooltip or indicator.

4. **Kiosk Multi-Grid Fullscreen Mode (`client/src/pages/LiveViewPage.tsx`)**:
   - Toggle button in live view header for Kiosk Fullscreen mode.
   - Hides navigation sidebar and top app header when active.
   - Listens to `fullscreenchange` and `Escape` key to sync state.

## Verification
- `npm run build:client` succeeds with 0 TypeScript/bundler errors.
- Test snapshot trigger, zoom/pan transform calculations, and kiosk fullscreen toggle.
