<threat_model>
### ASVS L1 Threat Model: Clip Export & Bookmarking UI
- **T-10-01 (Export Request Flooding)**: User clicks export button repeatedly, triggering duplicate background transcode jobs and overloading the server.
  - *Mitigation*: Client disables submit button and displays loading progress during job generation.
- **T-10-02 (Unauthorized Access Exposure)**: Users without export permission see active download controls.
  - *Mitigation*: Gated by `canExportClips` and role checking; UI hides the Export button if permission is absent.
</threat_model>
