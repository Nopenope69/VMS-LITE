<threat_model>
### ASVS L1 Threat Model: PTZ Frontend Controls
- **T-09-01 (Pointer Drift / Stuck Movement)**: User presses direction button and drags pointer outside button or browser window without triggering `mouseUp`, causing continuous movement.
  - *Mitigation*: Client registers both `onPointerUp` and `onPointerLeave` / `window.onpointerup` to ensure immediate `stop()` dispatch; server-side 1500ms watchdog backs it up.
- **T-09-02 (UI Desynchronization / Unauthorized Action)**: Non-permitted operators attempt to trigger PTZ actions via client tampering.
  - *Mitigation*: Client disables or hides PTZ UI if `canControlPtz` is false; API enforces strict 403 on backend.
</threat_model>
