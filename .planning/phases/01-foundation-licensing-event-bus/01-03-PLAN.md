<threat_model>
<threat>
T-01-06: Privilege escalation from Viewer to Admin
Severity: high
Mitigation: Enforce role claims in JWT and verify role permissions via strict server-side pre-handlers (`requireRole('ADMIN')`). Never rely on client-asserted roles.
</threat>
<threat>
T-01-07: Credential stuffing or weak password storage
Severity: high
Mitigation: Hash all user passwords using bcrypt with at least 10 salt rounds. Enforce minimal password length.
</threat>
<threat>
T-01-08: Database flooding or starvation via uncontrolled event dispatch
Severity: high
Mitigation: Validate event payloads with Zod schemas before emitting and write to PostgreSQL asynchronously with managed error handling.
</threat>
</threat_model>
